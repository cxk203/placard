# Placard 稳定性加固设计

## 目标

提升 `.tendies` 导入、在线目录、安装失败处理和动态预览的可靠性；保持当前主分支仅接受 `.tendies` 的产品边界，不恢复 `.tendiex` 或 `.zip` 支持。

## 范围

1. 下载与导入的壁纸包在写入 PosterBoard 前进行结构验证，并对加密或不可读取的 ZIP 返回明确错误。
2. 将每次安装的写入路径作为事务记录；任何后续步骤失败时仅删除本次已写入目录。
3. 目录源独立加载、汇报状态，并在远程目录无效时保留最后一次有效缓存。
4. 支持目录条目提供的可选 SHA-256；仅在提供且格式正确时校验，不破坏旧目录。
5. 限制动画预览的解码帧数、像素和缓存成本。
6. 新增可在 macOS CI 中执行的单元测试，覆盖目录解析、包验证、校验和与回滚计划。

## 设计

### 包验证与安装事务

创建独立的 `WallpaperPackageValidator`，接受解压目录并返回已验证的描述符分组。验证器要求每个描述符包含锁屏角色文件、数值标识符、`versions/1/contents`、至少一个 `Wallpaper.plist`，并检查每个 `Wallpaper.plist` 中引用的 `.ca` 目录存在。ZIP 无法打开、条目读取失败或解压失败统一映射为可读的包错误；系统无法解密的加密包使用“受密码保护或无法读取”的错误文案。

`BadQuery.writeDescriptors` 返回成功路径并在同一调用内补偿删除已复制项目。`WallpaperInstaller` 跨 provider 分组维护累计路径，若后续 provider 失败则调用新的 `removeDescriptors(paths:)` 回滚。

### 在线目录

将 Plus 下的每个源封装为带名称、URL、解码器和可选基础 URL 的 `WallpaperCatalogSource`。每个源返回 `CatalogSourceResult`（成功条目或失败原因）。主列表继续使用所有成功源；失败源被保留到 UI 的状态区域。远程数据缓存保存最后一次成功的原始目录，刷新失败时回退缓存并标为 stale。

解析社区目录的 `sha256` 可选字段。下载完成后，如果当前壁纸存在格式正确的 64 位十六进制 SHA-256，则对临时包计算哈希并严格比较；无哈希时沿用当前兼容行为。

### 动态预览

缩略图模式只取首帧。详情动画限制为固定最大帧数和缩略图像素数，并以解码像素成本写入 `NSCache.totalCostLimit`。过长 GIF 以抽样帧播放，避免将所有帧常驻内存。

## 不做的事

- 不增加 `.tendiex`、`.zip`、密码输入或密码破解。
- 不把 Mwallx 等没有稳定公开清单接口的网站抓取进应用。
- 不修改 PosterBoard 的私有访问机制或硬编码路径版本策略。
